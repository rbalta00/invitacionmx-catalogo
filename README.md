# Invitamx Catálogo

Catálogo interactivo de temas para invitaciones XV.

## Tech Stack

- Next.js 14
- TypeScript
- Vercel

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

Abre [http://localhost:3000](http://localhost:3000)

## Build

```bash
npm run build
npm run start
```

## Env Variables

```
NEXT_PUBLIC_WHATSAPP_NUMBER=2217445410
```

## Flujo

1. Cliente ve los 12 temas
2. Cliente selecciona uno
3. Se abre WhatsApp con mensaje pre-llenado
4. Cliente contacta a través de WhatsApp

## Deployment

Conectar a Vercel y deployer en `catalogo.invitamx.online` o subdominio similar.
